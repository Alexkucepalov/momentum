# Инструкция тестировщику — Momentum Friends Beta

Спасибо, что пробуешь приложение. Momentum считает питание **на устройстве**, без обязательного аккаунта.

## Установка

1. Получи APK и проверь, что в сообщении указаны **версия / git SHA / sha256**.  
2. На Android разреши установку из неизвестного источника для этого файла.  
3. Установи и открой Momentum.

## Что попробовать (15–20 минут)

1. Пропусти цели, если спросит — сразу добавь завтрак.  
2. Найди продукт поиском, поставь граммы, сохрани.  
3. Измени порцию у уже записанного пункта (или удали и добавь снова).  
4. Нажми быстрый повтор (+) у недавнего — убедись, что запись одна.  
5. Добавь свой продукт списком названий без калорий.  
6. Сохрани простой рецепт и добавь порцию в дневник.  
7. Открой «Что съесть сейчас?» и поищи знакомое название.  
8. Полностью закрой приложение и открой снова — записи на месте.  
9. В Профиле → «Данные» → **Экспорт JSON в буфер** (резервная копия). Сохрани текст в файл на телефоне или в заметки. Импорт заменяет все локальные данные — только если осознанно восстанавливаешь.

## Как сообщить об ошибке

Создай GitHub Issue или напиши в канал, который дал основатель. Укажи:

- версию APK / sha256 / дату сборки  
- модель телефона и версию Android  
- шаги  
- ожидание vs факт  
- скриншот **без** личных данных о питании (или замажь названия)

**Не присылай** полный дневник с реальными продуктами без явного согласия на разбор.
