# Release notes — Friends Beta (prep)

**Channel:** sideload APK (not Play Store)  
**Related:** [#120](https://github.com/Alexkucepalov/momentum/issues/120)

## What’s in the beta

Offline nutrition diary, catalog + my products, recipes (including text import), Eat Now, week plan, activity/water/habits, progress and local backup.

## What changed for this prep sprint

- Clearer portion wording for recipes vs packaged products  
- Honest weekly totals when there is no food log  
- Clearer habit weekly summary  
- Eat Now search finds products by alias and recipes by ingredients  
- Less duplicate navigation on Today and Profile  
- Single primary create path emphasis on Recipes list  
- Release documentation under `docs/release/`

## What we cut on purpose

Pantry, shopping list commerce, budget, receipts — see ADR-009. Not coming back for this beta.

## Limitations

Android Pass still requires physical devices. Backup is local JSON export/import. No account sync.
