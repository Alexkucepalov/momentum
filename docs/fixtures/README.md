# Фикстуры для dogfood UI

Синтетические данные только. Не реальные health-записи.

## Личные рецепты (архив)

`personal-recipes-expanded.json` — 38 рецептов/идей из переписки (`momentum.recipe_import.v1`).  
В приложении: **Рецепты → иконка библиотеки** — превью, выбор, импорт без тихого bulk и без выдуманных КБЖУ.  
Подробности: `personal-recipes-README.md`.

## Встроенный справочник продуктов

Офлайн-каталог обычных продуктов (~50 шт.) живёт в `src/domain/commonFoodCatalog.ts` (id `seed:*`, бренд «Справочник»).  
КБЖУ — справочные на 100 г из публичных таблиц состава; пользователь может править. Поиск в «Добавить еду» идёт по имени и синонимам, не только по штрихкоду.

### Как загрузить (рекомендуется)

В приложении: **Профиль → «Загрузить демо 2 недели»** — фикстура уже внутри APK, буфер не нужен.

### Альтернативы

| Способ | Когда |
|--------|--------|
| **Загрузить демо 2 недели** | Быстрый dogfood UI |
| **Вставить JSON** | Скопировал текст на телефоне и вставил в поле |
| **Импорт из буфера телефона** | JSON уже в буфере **Android** (не Mac) |

`pbcopy` на Mac **не** попадает в буфер телефона — поэтому «Импорт из буфера» часто кажется «сломанным».

### Важно

- Импорт **перезаписывает** все локальные данные. Сделай экспорт JSON, если жалко текущий дневник.
- Имена с суффиксом `Fixture` — чтобы не путать с реальными продуктами.
- Копии в приложении: `apps/mobile/src/fixtures/dogfood-2weeks.json` (бандл) и `apps/mobile/assets/fixtures/` (зеркало).
- Нужен APK, собранный **после** добавления кнопки — старый `moment.apk` демо не содержит.
