# Measurement plan (privacy-conscious)
## North star
Number of weeks with ≥4 meaningful active days AND at least one logged nutrition/activity/habit event. This is a hypothesis and should not reward excessive tracking.
## Funnel
Install → first non-AI food log → repeat log → day-7 return → week-4 meaningful use.
## UX
Median/p90 seconds to repeated meal save; add-food abort rate; barcode hit rate; manual fallback success; recipe completion; duplicate imports; missing nutrition fields rate; crash-free sessions.
## Habits
Weekly target attainment, user-controlled snooze/rest, opt-out rate from reminders, users reporting feeling encouraged (survey).
## AI
Proposal confirmation/edit/rejection, factual error/unknown fraction, cost per accepted action, tool calls, opt-in rate; measure value not quantity of AI tokens.
## Guardrails
No detailed food names, weights, biometrics or raw health metrics in default analytics. Opt-in anonymous aggregated diagnostics, local-only analytics by default, privacy deletion test.
## Experiments
A/B optional onboarding vs progressive setup (only after meaningful sample); quick-add last quantity vs default 100g; recent sorting; challenge weekly vs daily target.
