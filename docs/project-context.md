# nf-fit — project context

Product name: **nf-fit** (working title in chat: nothing fit). Platform: Android. Stack: Expo, React Native, TypeScript, Expo Router, SQLite. Architecture: offline-first, feature-oriented, domain-driven.

Git remote may remain `Alexkucepalov/momentum` until a rename is possible; installable branding is **nf-fit**.

## Mission

Personal nutrition, activity, habits, and progress — without medical framing, social network pressure, or invented nutrition numbers. Repeat meal logging ≤10s. User owns data (export / import / delete). No shame UX.

## Bottom tabs

Today · Food · Activity · Progress · Profile

Secondary (not tabs): Plan, Recipes, Shopping, Pantry, Budget.

## Visual direction

**Minimal Soft Utility** (default light skin) — see `docs/04-DESIGN-SYSTEM.md` and `docs/visual-direction.md`.

Home-screen Android widgets are in product scope (plan early; implement after Today metrics are real). See ADR-010.

## Roadmap phases

0 Foundation → 1 Nutrition core → 2 Recipes → 3 Today + Profile → 4 Activity + Progress → 5 Food planner → 6 Quality + beta widgets polish.
