# UX specification
## Principles
1. One-tap frequent actions; don't mandate AI, internet, camera or account to log food.
2. Clear provenance: user-entered, label, external catalog, AI estimate, missing.
3. Never shame; no red warning for missed habit or exceeded calories; rest is valid.
4. Progressive disclosure. 4 tabs Today / Food / Activity / Progress; quick-add accessible in 1 tap on every main tab.
5. No dark-pattern monetization; accessible large targets; keep important labels visible.
## Information architecture
Today: energy overview, quick-add, 1–3 suggested actions, habit cards, recent activity.
Food: daily summary, macros, meal groups, sticky add, recent/favorites, recipes, search, scan.
Activity: workouts list, manual entry, import source attribution, weekly totals, no duplicate count.
Progress: trends, flexible challenges, milestones, measurements, exports/settings.
## Screens
S01 Welcome: optional onboarding; goal type and modules, user may skip.
S02 Today: summary cards and core actions; no endless feed.
S03 Add food bottom-sheet: segmented Recent / Search / Scan / Manual; remembered meal and grams.
S04 Food result: name, 100g nutrition, source, serving grams, save. No silent auto-save after scan.
S05 Create food: required name + per 100g kcal OR macro nutrients; display inconsistencies for confirmation.
S06 Recipe builder: ingredients and quantities → cooked yield → per100g and portion preview → save.
S07 Daily diary: meal groups, edit amounts, delete/undo, dates, export.
S08 Habits/challenges: choose flexible weekly frequency, avoid broken streak punishments.
S09 Activity: manual duration/type, optional stats, source, duplicate warning.
S10 Insights: 7d and 30d trend, transparent missingness.
S11 Settings: privacy, AI opt-in, export, delete, permissions.
## UX flows
Repeat meal: Today > + > Recent > one-tap add (if configured) > toast Undo; long-press/options edit grams.
Novel packaged food: + > Scan > recognized code > local/cache/API lookup > confirm grams > Save; if none, capture label or manual creation.
Cooked batch: Recipes > New > add weighted raw ingredients > enter final cooked weight > save > log portion.
Challenge: Progress > New challenge > metric/source > weekly quantity/frequency > review > activate.
Import activity: Activity > Connect source / file > consent > preview > duplicate detection > confirm.
## Loading/error/offline
Optimistic local writes with undo. Camera permission denied → type barcode. API outage → own catalog still works. Partial nutrition → explicit unknown, not zero. Empty state → specific one-tap action. Use 44–48dp touch targets, scalable text, screen-reader labels, contrast tested.
## Onboarding
3 short optional steps: objective, interests, coaching style; no mandatory weight/sex/date of birth; no forced calorie prescription. First successful food entry should occur before account requirement.
