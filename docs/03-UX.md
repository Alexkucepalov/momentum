# UX specification

**Updated 2026-11-01.** Stage 3 IA: see `docs/PRODUCT-ROADMAP.md`.  
**Tabs:** Сегодня · Питание · Движение · Прогресс · Профиль.

## Principles
1. One-tap frequent actions; don't mandate AI, internet, camera or account to log food.
2. Clear provenance: user-entered, label, external catalog, Garmin/Zepp, missing.
3. Never shame; no red warning for missed habit or exceeded calories; rest is valid.
4. Progressive disclosure. Target **5** tabs: Today / Food / Movement / Progress / Profile. Quick-add in 1 tap from Today/Food.
5. Shared `dateLocal` across Today, Food, Movement (activity+sleep), reports.
6. No dark-pattern monetization; accessible large targets; keep important labels visible.
7. Analysis via **user-initiated** report copy/PDF — no silent third-party upload.

## Information architecture (target)
Today: energy overview, water, activity glance, one primary Add, habits below fold.
Food: diary / catalog segments, macros, meal groups, sticky add, recent/favorites, recipes, scan.
Movement: Activity | Sleep segments; workouts, steps, sleep stages; Garmin attribution.
Progress: week/month overview, habits/challenges, reports (PDF + ChatGPT text).
Profile: goals, body, Garmin/Zepp, day-report copy, export/import, privacy.
Stacks: `/recipes/*`, `/plan/*` (planner ≠ diary), `/garmin/*`.

## UX flows
Repeat meal: Food/Today → copy yesterday / recent → confirm grams → Undo.
Novel packaged food: + → Scan → OFF lookup → confirm grams → Save.
Cooked batch: Recipes → yield → portion → diary snapshot.
Garmin: Profile → Garmin → save Personal API Key → full/incremental sync → Activity/Sleep.
Report to ChatGPT: Profile or Progress → copy day/period text → paste manually.
Challenge: Progress → personal metrics; no broken-streak punishment.
Import activity: Garmin sync preferred; manual workout remains.
## Loading/error/offline
Optimistic local writes with undo. Camera permission denied → type barcode. API outage → own catalog still works. Partial nutrition → explicit unknown, not zero. Empty state → specific one-tap action. Use 44–48dp touch targets, scalable text, screen-reader labels, contrast tested.
## Onboarding
3 short optional steps: objective, interests, coaching style; no mandatory weight/sex/date of birth; no forced calorie prescription. First successful food entry should occur before account requirement.
