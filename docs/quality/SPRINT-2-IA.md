# Sprint 2 — Информационная архитектура

**Принцип:** не 6-й tab и не новые модули — **роль** каждого существующего входа.

---

## Корневые вкладки (как есть — 5)

```
┌─────────┬─────────┬───────────┬──────────┬─────────┐
│ Сегодня │ Питание │ Активность│ Прогресс │ Профиль │
└─────────┴─────────┴───────────┴──────────┴─────────┘
     │         │          │           │         │
     │         │          │           │         └─ цели, вода, export, privacy
     │         │          │           └─ вес, неделя еды, привычки, челленджи↓
     │         │          └─ тренировки дня
     │         └─ ДНЕВНИК дня + (сегмент) КАТАЛОГ
     └─ «что сделать сейчас»: статус дня + ДОБАВИТЬ + recent
```

### Роли (to-be)

| Tab | Одна фраза | Primary |
|-----|------------|---------|
| **Сегодня** | Статус дня и быстрый лог | **Добавить еду** / повтор Recent |
| **Питание** | Правка дневника и поиск еды | Дневник по слотам; сегмент Каталог |
| **Активность** | Спорт за день | Добавить тренировку |
| **Прогресс** | Тренды без шума | Вес + неделя ккал (habits secondary) |
| **Профиль** | Настройки | Сохранить цели |

Stacks (не tabs): `/plan/*`, `/recipes/*` — из Food header / Today secondary / sheet.

## Today — зоны (to-be)

```
1. Дата (компактно)
2. КБЖУ / ring          ← статус, не CTA
3. [ Добавить еду ]     ← ЕДИНСТВЕННЫЙ primary
4. Недавно (3–6)        ← one-tap / portion
5. ─── ниже fold ───
6. План на сегодня      ← secondary (если есть), иначе deep-link «Составить»
7. Привычки / вода      ← secondary
8. Ссылки: План · Рецепты · Сейчас   ← text links, НЕ 4 chip-кнопки равного веса
```

**Убрать с above-fold:** JourneyShortcuts как равные CTA; конкурирующий «план» рядом с Add.

---

## Food — зоны (to-be)

```
Header: дата | [План]
Segment:  [ Дневник ]  [ Каталог ]
────────────────────────────────
Дневник:  ring/strip опционально компактно
          слоты завтрак…перекус + edit/delete
          sticky [+] → AddFoodSheet
────────────────────────────────
Каталог:  поиск
          фильтры / частые / избранное / рецепты-в-каталоге
          БЕЗ полного дубля «добавить как на Today»
```

**Правило:** лог «на автомате» живёт на Today; Food = **исправить день** + **найти еду**.

## Recipes stack — единый вход (to-be, без новых фич)

```
Рецепты (index)
  ├─ Мои рецепты (список)
  ├─ Из текста
  ├─ Мой архив (import-personal)
  └─ из AddFoodSheet tab «Рецепты» → тот же index / deep link
```

Copy: везде одна формулировка «Рецепты», не три разных «архив/каталог/план».

---

## Plan stack — один сценарий (P2 glue)

```
План (hub)
  1. Что съесть сейчас?     → eat-now
  2. Меню на неделю         → week
  3. Запасы                 → pantry
  4. Покупки                → shop
  5. Бюджет / магазины      → secondary / «Ещё»
```

Не добавлять сущности — только порядок и copy.

## Карта «где искать еду» (устранение путаницы)

| Нужно | Куда идти |
|-------|-----------|
| Быстро повторить | Сегодня → Недавно |
| Поправить граммы сегодня | Питание → Дневник |
| Найти продукт | Питание → Каталог **или** Добавить → поиск |
| Свой рецепт | Рецепты |
| Вставить из чата | Рецепты → Из текста |
| Архив переписки | Рецепты → Мой архив |
| Что съесть по остатку | План → Сейчас |
| Меню недели | План → Неделя |

Эта таблица должна появиться как короткий hint в empty states (не новый экран).
