# Garmin device QA checklist (Stage 7 · L1–L5, L12)

Ручная проверка на физическом Android. Не коммитить реальные ключи / payload.

| ID | Проверка | ☐ |
|----|----------|---|
| L1 | Personal API key → «Сохранить и проверить» → статус «Подключено» | |
| L2 | Полная выгрузка завершается без краша; вес/тренировки/шаги/сон растут | |
| L3 | «Обновить с последней даты» тянет только инкремент (короче полной) | |
| L4 | Sleep night с реальной ночи: sleepSec / stages / score не выдуманы | |
| L5 | Движение → Сон: стадии + легенда; пустая ночь = «—», не 0 ч | |
| L6 | `garmin-last-sync` показывает время последней успешной | |
| L7 | Предупреждения свёрнуты в блок, раскрываются тапом | |
| L12 | Просроченный/неверный ключ → понятная ошибка; новый ключ заменяет старый | |
| L13 | Ключ и bearer только в SecureStore (не в JSON export) | |
