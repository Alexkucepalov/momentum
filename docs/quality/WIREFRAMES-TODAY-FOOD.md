### Acceptance (S2-1 Today)

- [ ] Above-fold: дата + КБЖУ + **один** primary «Добавить еду» + recent ≤6  
- [ ] JourneyShortcuts не как 4 равные кнопки (убрать или заменить text links ниже)  
- [ ] Plan strip не выше primary Add  
- [ ] Meal chips не обязательны above-fold (meal выбирается в sheet / контекст)  
- [ ] Empty recent: copy + CTA добавить  
- [ ] v13 / verify / screenshot before-after  
- [ ] Dogfood: Flow 1 из `DEVICE-DOGFOOD` или короткий повтор  

### Скрыть / перенести

| Элемент | Действие |
|---------|----------|
| JourneyShortcuts chips | Убрать с fold → text links «Ещё» |
| AddFoodBlock meal row | В sheet / ниже |
| Copy yesterday | Secondary под recent или в Food |
| TodayPlanStrip | Ниже primary; empty → одна строка-ссылка |

### Acceptance (S2-2 Food)

- [ ] Default segment = **Дневник**  
- [ ] Каталог не виден одновременно с полным списком слотов (segment switch)  
- [ ] Sticky + открывает AddFoodSheet  
- [ ] Поиск живёт в Каталоге (и/или sheet) — без третьей «строки поиска» на Дневнике  
- [ ] Week strip: оставить compact **или** убрать с default (решение в PR: prefer keep 1 row)  
- [ ] verify + screenshots + dogfood Flow 3
