# Recipe discovery map (S2-4)

**Цель:** founder находит «повторить / добавить рецепт» ≤3 тапа.

| Нужно | Где | Тапы |
|-------|-----|------|
| Повторить недавнее блюдо | Сегодня → Недавно **+** / Add sheet → Недавние | 1–2 |
| Найти рецепт по имени | Питание → **Каталог** → поиск / фильтр Рецепты | 2–3 |
| Библиотека рецептов | header Питание → книга **или** Профиль shortcuts | 1–2 |
| Импорт из текста / архив | Рецепты → блок «Добавить рецепт» | 2 |
| Что съесть из рецептов | План → Что съесть сейчас | 2 |
| Меню / покупки | План → Меню / Покупки | 2 |

**Не дублировать:** полный каталог продуктов живёт в Питание → Каталог; Рецепты = библиотека готовки + импорт.
