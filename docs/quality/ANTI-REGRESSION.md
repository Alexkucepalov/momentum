**Почему этот файл:** 2026-11-08…09 часть PR по аудиту сама сломала уже рабочее поведение на телефоне. Дальше «улучшение из отчёта» **не** важнее уже принятого UX.

## Правило merge

1. `npm run verify` — необходимо, **недостаточно**.  
2. Любой PR, который двигает Food / порции / Garmin chrome / sleep clocks / widgets → после merge (или до) короткий device smoke из таблицы ниже.  
3. Рекомендация аудита, которая **меняет порядок** привычных зон (Повторить, footer, баннеры) — только с явным «ок» основателя на устройстве, не со скриншота пустого состояния.  
4. Не чинить «по скрину пустого экрана» то, что на заполненном дне уже устраивает.
