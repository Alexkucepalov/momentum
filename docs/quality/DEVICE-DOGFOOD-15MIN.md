## 1. Сохранность (≈5 мин) — #36

1. Открой приложение → **Питание** или **Сегодня**.
2. Добавь продукт (Recent или поиск) → подтверди граммы → увидь flash и строку в дневнике.
3. Запомни: имя, граммы, примерные ккал дня.
4. **Force-stop:** Настройки Android → Приложения → Momentum → Остановить / Force stop.  
   (или Recent apps → свайп + «очистить», если force-stop недоступен — укажи метод).
5. Снова открой Momentum.
6. **Ожидание:** та же запись на том же дне, totals не обнулились.

| Check | Pass? | Note |
|-------|-------|------|
| Entry after relaunch | | |
| Totals consistent | | |

Скриншот: дневник до kill + после relaunch.

## 2. Guard: двойной тап vs намеренно два раза (≈4 мин) — #35

### 2a. Случайный двойной тап
1. На **Сегодня** быстро 2–3 раза тапни один и тот же Recent (или «Добавить»→тот же пункт).
2. **Ожидание:** **одна** новая запись (или одна порция), не две-три за &lt;0.5 с.

### 2b. Намеренно два раза тот же продукт
1. Добавь продукт → дождись flash (~1 с).
2. Снова добавь **тот же** продукт (или открой sheet и добавь ещё раз).
3. **Ожидание:** **вторая** запись появляется (два раза по N г или две строки).

| Check | Pass? |
|-------|-------|
| Rapid double → ≤1 | |
| After pause → 2nd add OK | |
