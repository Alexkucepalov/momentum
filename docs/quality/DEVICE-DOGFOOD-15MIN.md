## 1. Сохранность (≈5 мин) — #36 / #92

1. Открой приложение → **Питание** или **Сегодня**.
2. Добавь продукт (поиск / «Повторить» на Питании) → подтверди граммы → flash и строка в дневнике.
3. Запомни: имя, граммы, примерные ккал дня.
4. **Два разных kill-сценария — отдельные строки:**
   - **Recent swipe:** свайп из недавних приложений (не force-stop).
   - **Force-stop:** Настройки Android → Приложения → nf-fit / Momentum → Принудительно остановить.
5. Снова открой приложение после каждого сценария.
6. **Ожидание:** та же запись на том же дне, totals не обнулились; удалённые ранее записи не вернулись.

| Check | Pass? | Note |
|-------|-------|------|
| Entry after Recent swipe | | |
| Entry after force-stop | | |
| Totals consistent | | |
| Deleted stay deleted | | |

Скриншот: дневник до kill + после force-stop.

## 2. Guard: двойной тап vs намеренно два раза (≈4 мин) — #35

### 2a. Случайный двойной тап
1. На **Питание** (или sheet) быстро 2–3 раза тапни один и тот же Recent / «Повторить».
2. **Ожидание:** **одна** новая запись (или одна порция), не две-три за &lt;0.5 с.

### 2b. Намеренно два раза тот же продукт
1. Добавь продукт → дождись flash (~1 с).
2. Снова добавь **тот же** продукт.
3. **Ожидание:** **вторая** запись появляется.

| Check | Pass? |
|-------|-------|
| Rapid double → ≤1 | |
| After pause → 2nd add OK | |

## 4. Замер повторного добавления ≤10 с (≈3 мин) — #37

Два отдельных замера (не смешивать):

### 4a. От открытия вкладки
Секундомер: старт когда открыл **Питание** → найти «Повторить» / Recent → тап → порция → строка/flash.

### 4b. От уже найденной кнопки
Секундомер: палец уже над кнопкой повтора → тап → … → flash.  
**4b не проверяет находчивость** — только механику подтверждения.

Повтори **5 раз** каждый контур (можно один продукт). Сохрани **все пять**, медиану и **max** (медленные попытки не прятать одной медианой).
