# Strength module (силовые) — PRD slice

**Статус:** Program + session UX + volume/PRs + template editor (#206–#215). True DnD / Google Calendar later.  
**ADR:** ADR-011 in `docs/14-DECISIONS.md`  
**Философия:** быстро в зале (≤15 с до записи подхода), шаблон ≠ факт, без стыда за перенос, без 6-й вкладки.

**Редактор шаблона:** `/strength/template/[id]` — добавить/убрать упражнения, порядок ▲▼, подходы/повторы/отдых; сид каталога не затирает правки пользователя. На неделе: Выше/Ниже в дне + «Изменить шаблон».

## Личная программа (dogfood)

- Старт: понедельник **16.11.2026**
- Неделя: Верх A → Ноги+пресс → отдых → Верх B → велостанок (зона 2) → Верх C → отдых
- Рабочие подходы: **2** на упражнение; RIR 2–3; отдых 60–120 с
- Кнопка «Программа / Повторить программу» на доске недели заполняет `PlannedActivity` без правки истории сессий

## Экраны

| Зона | Поведение |
|------|-----------|
| Движение | День → план карточками → Начать; записи/Garmin вторично |
| Сегодня | Ближайшая плановая + «Начать» (после Stage 02) |
| Прогресс | Рабочий вес × повторы по упражнению (Stage 03) |
| Питание | Без авто-возврата ккал тренировки |

## Сущности (snapshot v20)

- `Exercise` — справочник  
- `WorkoutTemplate` + `WorkoutTemplateExercise` — многоразовый план  
- `PlannedActivity` — событие на дату (сила / кардио / отдых)  
- `WorkoutSession` + `WorkoutSet` — факт; перенос плана **не** меняет историю  

## Этапы

1. Конструктор + журнал + черновик после kill  
2. Недельная доска: меню Перенести / Копировать (drag позже)  
3. Аналитика силы  
4. Google Calendar — отдельно  

## Anti-regression

Не трогать Food order, Garmin overlay, portion grams, sleep GMT, widget revision (`ANTI-REGRESSION.md`).
